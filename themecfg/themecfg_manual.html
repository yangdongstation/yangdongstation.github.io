界面语言（网站语言）

本主题自带 11 套界面文本：zh-Hans（简体中文）、zh-Hant（繁體中文）、ja（日本語）、en（English）、ko（한국어）、pt（Português）、es（Español）、fr（Français）、de（Deutsch）、ru（Русский）、ar（العربية，从右到左）。同一套注册表同时决定界面文字、<html lang>、文字方向与排版标度，因此新增语言不会出现“文字换了但版心没换”的错位。

网站语言 接受三类写法，大小写与下划线不敏感（zh_CN、ZH-CN 等价）：

写法示例结果
标准 BCP-47 标签zh-Hans、pt-BR、de-AT最长前缀匹配；pt-BR → pt，de-AT → de。
BBG 旧版语言名简体中文、繁體中文、日本語、English、한국어、Русский、العربية经别名表映射到对应标签，旧站点无需改动。
英文语言名与短码chinese、japanese、english、zh、jp、chs、cht同样走别名表；zh-HK/zh-TW/zh-MO 归为 zh-Hant。
auto / 留空auto、自动、跟随系统、空字符串交给浏览器：依次尝试 navigator.languages、navigator.language。

无法确定时为 English：当语言完全无法判定（标签无法识别、localStorage 损坏、auto 且浏览器语言不在支持列表内），主题显示英文 en，而不是中文。完整回退链为：localStorage['antiphon:lang']（非 auto）→ 网站语言（非空且非 auto）→ 浏览器语言 → en。字符串级别同理：当前语言包 → （仅繁体中文时）简体中文包 → en → 原始键名。除繁体中文外，任何语言缺失字符串都不会回退到中文。

读者可在右上角地球图标中自行切换；选择写入 localStorage['antiphon:lang'] 并优先于 网站语言，选“跟随系统”会清除该键。auto 那一行会附带显示当前实际解析到的语言，便于确认自动结果。日期、月份与数字均按解析到的语言用 Intl 格式化（zh-Hans/zh-Hant 由浏览器原生 CLDR 数据区分，无需再映射到 zh-CN/zh-TW）。

评论组件会把解析到的标签传给 Valine / Waline / Rustaline / Disqus；仅中文会被改写成 zh-CN 或 zh-TW，其余标签原样传递。

字体预设（字体）

右上角“字体”图标提供四套预设，选择存入 localStorage['antiphon:font']，与界面语言相互独立。每套预设只替换拉丁字面，CJK、谚文与阿拉伯文的回退字族始终保留，因此不会出现中文掉字。

多语言

主题界面文案（导航、分区标题、日期、分页、页脚等）随界面语言在 11 种语言之间切换：zh-Hans、zh-Hant、ja、en、ko、pt、es、fr、de、ru、ar。界面语言按「访客选择 → 站点设置 网站语言 → 系统语言 → en」的顺序解析；网站语言 留空或填 auto 表示交给系统。阿拉伯语会自动切换为 RTL 排版。

文章与页面的正文不翻译。正文是作者用自己语言写的内容，主题不会、也不应该改写它；切换语言只影响界面，正文照原样显示。

如果希望文章标题、摘要等元数据也跟随语言，可在站点内放置可选的 data/i18n.json，其结构与站点配置同形、按语言分块：

{ "en": { "博客标题": "Antiphon", "文章列表": [{ "文件名": "08-psalm.md", "文章标题": "Psalm", "摘要": "…" }] } }

支持翻译的字段：博客标题、博客描述（副标题）、网站公告、底部信息（格式为markdown）、全站内容授权说明、友人帐页面附加信息、菜单中的外部链接、页面列表、文章列表、标签名称、友人帐。解析顺序为「当前语言 → en → 原文」，未提供的字段一律回落到原文，因此不写这个文件的行为与从前完全一致。
